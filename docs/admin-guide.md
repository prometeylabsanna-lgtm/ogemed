# Інструкція з користування адмінкою OGEMED

---

## 1. Як увійти

1. Відкрийте в браузері **адресу адмінки**, яку вам видав адміністратор сайту.
  > Адреса **не** виглядає як `/admin` — це зроблено навмисно з міркувань безпеки. Не шукайте її в Google і не публікуйте в чатах.
2. Введіть **логін** і **пароль**.
3. Натисніть кнопку входу.

```
┌─────────────────────────────────────────┐
│           OGEMED Admin                  │
│                                         │
│   Імʼя користувача  [______________]    │
│   Пароль            [______________]    │
│                                         │
│              [ Увійти ]                 │
└─────────────────────────────────────────┘
```

**Якщо не входить:** перевірте розкладку клавіатури, Caps Lock, чи не застарілий пароль. Зверніться до адміністратора — самостійно «скинути пароль через сайт» для адмінки зазвичай недоступно.

**Після входу** ви потрапляєте на головну панель із бічним меню зліва.

## 4. Загальні правила роботи

1. **Спочатку змінили → потім «Зберегти».** Без збереження зміни зникнуть після закриття вкладки.
2. **UA і RU.** Багато полів мають дві мови. Перемикач **UA | RU** показує відповідний набір полів. Заповнюйте обидві мови, якщо сайт працює двома мовами.
3. **«Активний» / «Опубліковано» / «Показувати…».** Якщо зняти галочку — блок або товар зникне з вітрини, але запис у адмінці залишиться.
4. **Не видаляйте «на всяк випадок».** Краще зніміть «Активний», ніж видаляйте товар чи секцію з історією.
5. **Фото.** Завантажуйте достатньо великі зображення; на мобільних вони обрізаються по центру. Формат: JPG/PNG/WebP; вага до 20 МБ (краще до 3 МБ). Для логотипу — PNG/SVG з прозорістю. У полів є підказки з розмірами та лімітом символів — не перевищуйте рекомендовану довжину текстів, інакше може зламатись верстка.
6. **Перевірка на сайті.** Після збереження відкрийте сторінку в новій вкладці (іноді потрібне оновлення Ctrl+R / ⌘R).
7. **Помилка під полем.** Червоний текст означає, що поле обовʼязкове або значення некоректне — виправте й збережіть знову.

## 6. Мови в інтерфейсі редактора

На сторінках вмісту та в картках товарів/категорій/брендів:

```
  [ UA ]  [ RU ]     ← перемикач мови полів
```

- **UA** — українські поля (`… (UK)`, `[UA]`, або просто «Назва» при активній вкладці UA).  
- **RU** — російські поля.

Текст у редакторі (TinyMCE) підтримує жирний, списки, посилання. Не вставляйте з Word «як є» великі фрагменти з дивним форматуванням — краще «Вставити як звичайний текст», якщо така опція є.

## 8. Налаштування сайту



### Куди натискати

**Ліве меню → Налаштування → Налаштування сайту**

Це **єдиний** запис (singleton): відкривається одразу форма. Окремого списку «додати ще один» немає — і не потрібно.

```
┌────────────────────────────────────────────────────────────┐
│  Налаштування сайту                                        │
│                                                            │
│  ▼ Контакти                                                │
│  ▼ Бренд                                                   │
│                                                            │
│  [ Зберегти ]  [ Зберегти і продовжити… ]                  │
└────────────────────────────────────────────────────────────┘
```

Після змін обовʼязково натисніть **Зберегти**.

> **Соцмережі** редагуються в **Вміст сторінок → Підвал сайту**.  
> **Реквізити ФОП** — у **Юридичні сторінки → Доставка і оплата** (або **Оферта**).

### Секція «Контакти»


| Поле                   | Що вводити                                                              | Де видно на сайті        |
| ---------------------- | ----------------------------------------------------------------------- | ------------------------ |
| **Телефон**            | Основний номер (з кодом країни)                                         | Шапка, контакти, футер   |
| **Телефон 2**          | Другий номер (необовʼязково)                                            | Там само, якщо заповнено |
| **Email**              | Публічна пошта магазину                                                 | Контакти, футер          |
| **Email менеджера**    | Внутрішня пошта для сповіщень / менеджера                               | Не обовʼязково публічна  |
| **Адреса (UK)**        | Фізична адреса українською                                              | Контакти                 |
| **Адреса (RU)**        | Те саме російською                                                      | Контакти (RU)            |
| **Години роботи (UK)** | Наприклад: «Пн–Пт 10:00–19:00»                                          | Контакти                 |
| **Години роботи (RU)** | Те саме російською                                                      | Контакти (RU)            |
| **Карта Google**       | Коротке посилання `maps.app.goo.gl/…` **або** HTML iframe з Google Maps | Блок карти на контактах  |




### Як вставити карту (покроково)

1. Відкрийте Google Maps → знайдіть точку → **Поділитися**.
2. Скопіюйте коротке посилання **або** вкладку «Вбудувати карту» → код iframe.
3. Вставте в поле **Карта Google**.
4. **Зберегти** → перевірте сторінку контактів.

> Підказка в адмінці: система сама нормалізує поширені формати посилань на карту.

3. Збережіть і перевірте шапку сайту на десктопі та телефоні.

1. Меню → **Налаштування сайту** → змініть **Телефон** → **Зберегти**.
2. Меню → **Вміст сторінок → Підвал сайту** → змініть **Instagram** → **Зберегти**.
3. Перевірте шапку / футер / контакти на сайті.

### 9.1 Головна — банер (hero)

**Меню → Вміст сторінок → Головна — банер**


| Поле / блок                  | Опис                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| **Показувати банер**          | Якщо зняти — банер на головній не показується                |
| **Заголовок без слайдів**    | Текст, якщо немає жодного активного слайда (до ~80 символів) |
| **Підзаголовок без слайдів** | Короткий підтримуючий текст                                  |




### Hero-слайди (карусель)

Кожен слайд:


| Поле                     | Опис                                                                   |
| ------------------------ | ---------------------------------------------------------------------- |
| **Зображення**           | Фонове фото. Desktop ≈ **1920×800**; на мобільному обрізання по центру. JPG/PNG/WebP, до 20 МБ (краще до 3 МБ) |
| **Заголовок (UK/RU)**    | Великий текст на слайді (рекомендовано до 80 символів)                 |
| **Підзаголовок (UK/RU)** | Менший текст (рекомендовано до 120 символів)                           |
| **Текст кнопки (UK/RU)** | Наприклад «До каталогу» (до 32 символів)                               |
| **Посилання кнопки**     | Куди веде кнопка (`/katalog/`, `/kontakty/` тощо)                      |
| **Активний**             | Чи показувати слайд у каруселі                                         |
| **Порядок**              | Черговість (менше число — раніше)                                      |


**Сценарій: замінити банер**

1. Відкрийте **Головна — банер**.
2. У потрібному слайді завантажте нове **Зображення**.
3. Оновіть заголовок / текст кнопки обома мовами.
4. Переконайтеся, що **Активний** увімкнено.
5. **Зберегти** → **Переглянути на сайті**.

### 9.9 Юридичні сторінки

**Меню → Юридичні сторінки →** потрібна сторінка (Про нас, Контакти, Доставка, Повернення, Конфіденційність, Оферта).

Клік по пункту відкриває **повний редактор** цієї сторінки.

На одній сторінці (залежно від типу):

1. **Заголовок і текст сторінки** — назва + **весь основний текст в одному редакторі** (абзаци, заголовки, відступи).
2. **Форма** і **бічна замітка** — окремо для доставки / повернення / конфіденційності / оферти.
3. Для **Про нас** — також банер, історія, філософія, кнопки (див. §9.8).
4. Для **Доставка / Оферта** — також реквізити ФОП.

```
┌────────────────────────────────────────────────────────────┐
│  Доставка і оплата          [UA] [RU]   [Переглянути]      │
│                                                            │
│  ▼ Заголовок і текст сторінки (один редактор)              │
│  ▼ Форма                                                   │
│  ▼ Бічна замітка                                           │
│                                                            │
│  [ Зберегти ]                                              │
└────────────────────────────────────────────────────────────┘
```

**Сценарій: змінити текст доставки**

1. Відкрийте **Юридичні сторінки → Доставка і оплата**.
2. У полі **Текст сторінки** відредагуйте весь контент (заголовки H2, абзаци).
3. За потреби оновіть **Форму** (заголовок / текст).
4. **Зберегти** → перевірте на сайті.

| Поле                                  | Опис                          |
| ------------------------------------- | ----------------------------- |

### 10.3 Сценарій: додати новий товар

1. **Каталог → Товари → Додати товар**.
2. Заповніть **SKU**, **Ціну**, **Залишок**, **Наявність = В наявності**.
3. **Статус = Активний**, оберіть **Бренд** і **категорії**.
4. Вкладка **UA**: назва, короткий опис, опис. Потім **RU**.
5. Оберіть **характеристики** (тип шкіри тощо).
6. Завантажте фото → позначте **Головне**.
7. За потреби: **Новинка** / **Хіт** / мітки / схожі товари.
8. **Зберегти** → відкрийте товар на сайті (кнопка перегляду, якщо є, або через каталог).

**Сценарій: акція**

1. Відкрийте товар.
2. Вкажіть **Стару ціну** (була) і нову **Ціну** (стала).
3. Увімкніть **Акція**.
4. Збережіть.

**Сценарій: зняти з продажу**

- **Статус = Неактивний** або масова дія «Зробити неактивними».  
Не видаляйте товар, якщо плануєте повернути його пізніше.

### 11.3 Статуси замовлення


| Статус            | Що означає                          |
| ----------------- | ----------------------------------- |
| **Нове**          | Щойно створене                      |
| **Очікує оплати** | Чекаємо оплату (типово для Monopay) |
| **Оплачено**      | Гроші отримано онлайн               |
| **В обробці**     | Менеджер збирає / готує відправку   |
| **Відправлено**   | Віддано в доставку                  |
| **Виконано**      | Успішно завершено                   |
| **Скасовано**     | Скасовано                           |




### Дозволені переходи (важливо!)

Система **блокує** недозволені стрибки. Правильна «драбина»:

```
Нове ──────────────► Очікує оплати ──► Оплачено ──► В обробці
  │                        │                            │
  │                        │                            ▼
  ├────────────────────────┼────────────────────► Скасовано
  │                        │
  └────────────────────────┴────────────────────► В обробці
                                                      │
                                                      ▼
                                                 Відправлено
                                                      │
                                                      ▼
                                                   Виконано

Виконано і Скасовано — кінцеві статуси (далі не йдуть).
```

Типові шляхи:


| Тип оплати при створенні | Стартовий статус | Далі                                          |
| ------------------------ | ---------------- | --------------------------------------------- |
| Monopay                  | Очікує оплати    | Оплачено → В обробці → Відправлено → Виконано |
| COD / ФОП                | В обробці        | Відправлено → Виконано                        |


Якщо зʼявиться помилка **«Заборонений перехід статусу»** — оберіть наступний дозволений крок, а не «стрибок» через етап.

---



### 11.4 Масові дії зі статусами

У списку замовлень позначте рядки → оберіть дію → **Виконати**:


| Дія               | Новий статус             |
| ----------------- | ------------------------ |
| **→ В обробці**   | В обробці (+ сповіщення) |
| **→ Відправлено** | Відправлено              |
| **→ Виконано**    | Виконано                 |
| **→ Скасовано**   | Скасовано                |


Дії також перевіряють дозволені переходи.

---



### 11.5 Сценарій: обробити нове замовлення

1. **Продажі → Замовлення**. За потреби фільтр **Статус = Нове** (або «В обробці»).
2. Відкрийте замовлення.
3. Перевірте **ПІБ, телефон, доставку, оплату, позиції**.
4. Звʼяжіться з клієнтом за потреби.
5. Змініть статус на **В обробці** (якщо ще не він) → **Зберегти**.
6. Після відправки в НП / курʼєру → **Відправлено** → **Зберегти**.
7. Після отримання клієнтом → **Виконано**.

**Скасування:** лише коли дійсно потрібно; зі статусів **Нове / Очікує оплати / В обробці** — дія **→ Скасовано**.

## 12. Користувачі, ролі та журнал дій



### 12.1 Хто що бачить


| Роль                            | Типовий доступ                                                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Суперкористувач**             | Усе: налаштування, контент, каталог, замовлення, оплати, користувачі                                                                            |
| **Менеджер** (група «Менеджер») | Каталог (без зайвого видалення), замовлення (перегляд/зміна), ліди. **Без** налаштувань сайту, юридичних сторінок, іконок міток у правах, оплат |


> Меню зліва показує лише те, на що є права. Якщо пункту немає — зверніться до адміністратора.

---



### 12.2 Список користувачів

**Меню → Користувачі → Користувачі**

```
┌──────────────────────────────────────────────────────────────┐
│  Користувачі                         [Додати користувача +]  │
│                                                              │
│  Імʼя користувача │ Email │ Staff │ Активний │ Дата реєстр.  │
│                                                              │
│  Фільтри: Активний │ Staff │ Суперкористувач                 │
└──────────────────────────────────────────────────────────────┘
```


| Колонка / прапорець             | Сенс                                |
| ------------------------------- | ----------------------------------- |
| **Імʼя користувача**            | Логін для входу в адмінку           |
| **Email**                       | Пошта                               |
| **Статус персоналу (is_staff)** | **Обовʼязково** для входу в адмінку |
| **Активний**                    | Якщо зняти — увійти не зможе        |
| **Статус суперкористувача**     | Повний доступ (обережно!)           |


---



### 12.3 Картка користувача

Проста форма (без груп, дрібних дозволів і профілю доставки):


| Поле                     | Опис                                          |
| ------------------------ | --------------------------------------------- |
| **Імʼя користувача**     | Логін                                         |
| **Email**                | Пошта (необовʼязково)                         |
| **Новий пароль**         | Введіть новий пароль. Порожньо = не змінювати |
| **Підтвердження пароля** | Повтор нового пароля                          |
| **Активний**             | Доступ до входу                               |
| **Статус персоналу**     | Потрібен для входу в адмінку                  |
| **Менеджер**             | Права на замовлення й каталог                 |
| **Суперкористувач**      | Повний доступ (обережно)                      |


---



### 12.4 Сценарій: створити менеджера

1. **Користувачі → Додати користувача**.
2. Вкажіть **логін**, **пароль** (і підтвердження) → збережіть.
3. На картці увімкніть **Активний**, **Статус персоналу** і **Менеджер**.
4. **Не** ставте суперкористувача без потреби.
5. **Зберегти**.
6. Передайте логін і пароль співробітнику **окремим захищеним каналом**.

---



### 12.5 Сценарій: заблокувати доступ

1. Відкрийте користувача.
2. Зніміть **Активний** (або **Статус персоналу**).
3. **Зберегти**.

Видалення акаунта — крайній захід (можуть бути привʼязані замовлення).

---



### 12.6 Недавні дії (журнал)

**Меню → Недавні дії**

```
┌──────────────────────────────────────────────────────────────┐
│  Недавні дії                                                 │
│                                                              │
│  Час │ Користувач │ Тип обʼєкта │ Обʼєкт │ Дія               │
```

- Лише **перегляд** (додати/видалити записи журналу не можна).
- Зручно зʼясувати: хто змінив ціну, статус замовлення чи текст сторінки.

### 12.7 Безпека — короткі правила

1. Не діліться паролем адмінки в месенджерах «для всіх».
2. Не публікуйте адресу адмінки.
3. Працюйте лише з офіційного робочого пристрою; виходьте з адмінки на спільних компʼютерах (**Вийти** у меню профілю).
